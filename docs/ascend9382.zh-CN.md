# Ascend910_9382 矩阵 intra 修复

2026-10-29。KDA/GDN2 的 9382 后端已切到 `kda_intra_npu9382.py`、
`gdn2_intra_npu9382.py`，与 residual 分离调度。原发布接口范围保持：
BF16 q/k/v、K=V128、等头数、C64、定长；仍需 `FDR_EXPERIMENTAL_NPU=1`。

旧 C64/K32 副本在大门跨度回退时使用带三角掩码的跨行系数加载，真实输入
的独立探针复现了 54 个错误位置。新实现采用合法地址加载和显式算术掩码，
沿原始 Ascend 数据流统一使用 32 行、64 通道工作块。原 chunk 和模型维度
不变；32×128 实际超出 192 KiB UB，32×64 通过验证。对角门跨度小于
80 个 log2 单位时用中心化 FP32 矩阵，否则保留成对差值直接求和。

既有 L/D、转置读取、点积输入和累加保持 FP32。KDA scalar beta 仍做 FP32
分片归约；GDN2 vector beta 直接写最终布局，省去重排和独立加法。GDN2
dq/dk 保持原 BF16 输出边界。没有 case 特化或通过修改结构追求收益。

远端 Ascend910_9382、B1T2048、冻结 FLA a59bc5df、同步 eager、原生 R、
真实 AdamW 更新，ABBA 每版本 60 个 STEP、30 个 B/FB 样本：

| 组合路径 | 完整 STEP | 整网 B | FB |
|---|---:|---:|---:|
| FLA 默认纯 KDA | 1.0436× | 1.0904× | 1.0529× |
| GDN2 官方关键尺寸的 FLA 移植控制 | 1.1527× | 1.4227× | 1.2083× |

对照是冻结 FLA Triton-Ascend 及双方相同的必要适配，不是 flashserve
AscendC 整套后端。GDN2 是公共 LM 骨架移植，不能当官方完整模型或预训练
权重结果。各行只报告该次同卡配对，不将独立 residual 与组合跨 run 相除。

真实 intra 回放及 14 个尾块/门跨度回归通过；18 项 CPU 调度/数学检查通过。
整网接口、命中、相同初始 loss、有限状态和实际更新检查通过，但全模型梯度
最大差异为 KDA 1.9432%、GDN2 2.1720%，仍有超预算项。性能探索不代表
原精度或长期训练收敛验收，也不构成完整新 wheel 的所有接口验收。

旧 AscendC KDA 和旧 GDN2 矩阵路径会将既有 FP32 L/D 转 BF16，已撤下
严格精度推荐且不再由 9382 默认调度选中。旧源码和构建脚本仅保留复现用途；
当前路径不需要原生库或它的常驻 scratch workspace。

公共[结果汇总](results.md)与[复现入口](reproduction.md)保留计时和数值范围；
实际 intra 回归输入在 `validation/npu950_intra/`。完整内部归档不随源码发布。
结果仅覆盖本次设备/工具链和模型执行条件；950的独立算子验收见[950说明](ascend950.zh-CN.md)。
